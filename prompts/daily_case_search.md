# Daily Case Search

比較的新しい皮膚科領域の画像付き症例または診断チャレンジ記事を1本探す。

## 探索

- 公開から12か月以内を優先する。
- CMAJ Clinical Images、JAMA Dermatology Clinicopathological Challenge、The Lancet Clinical Picture、BMJ Picture Quiz、JAAD Case Reportsなどを優先する。
- 皮膚科が主題で、臨床写真があり、本文と画像を閲覧できる症例形式に限る。
- 出版社またはPMC本文と、PubMedまたはDOI情報の両方で事実確認する。
- URLを実際に開き、`case_history.md`との重複を確認する。
- 画像のライセンスと表示方法を確認する。条件が不明なら採用しない。
- 候補と判断根拠を`search_log.md`へ記録する。

## 初回出力

初回は次の内容だけを日本語で提示する。

```text
## 本日の皮膚科クイズ

［表示許諾を確認した代表的な臨床写真1枚］

［診断に直結する情報を伏せた100〜200字程度の臨床経過］

**これは何でしょう？**
```

タイトル、仮題、雑誌名、日付、著者、DOI、PMID、URL、英語、診断名、決定的な病理・検査・治療は回答後まで表示しない。画像のキャプション、ファイル名、代替テキストからも診断を漏らさない。

条件を満たす症例を確認できなければ、無理に作らずその旨を記録する。
