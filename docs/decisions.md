# Design Decisions

## 2026-07-18: AI workspaceから実装を分離

- 実装、履歴、検索ログ、自動化設定はこの独立プロジェクトで管理する。
- AI workspaceにはプロジェクトの現在地と次の一手だけを置く。

## 2026-07-18: 第16節を優先

引き継ぎ文書の第16節が、それ以前に書かれた初回出題フォーマットを上書きする。

初回表示は次の3要素だけとする。

1. 許諾条件を確認できた代表的な臨床写真1枚
2. 100〜200字程度の日本語の臨床経過
3. `これは何でしょう？`

タイトル、書誌情報、URL、英語、診断に直結する情報は回答後まで表示しない。

## 2026-07-18: 手動MVPを先行

最初から配信アプリを作らず、まず専用チャットで数問を手動運用する。探索精度、重複防止、画像ライセンス、段階的ヒント、回答後開示を確認してから自動化方式を決める。

## 2026-07-18: 30症例プールを日替わり表示

- CC BY 4.0、患者同意、PMC本文、PubMed/DOIを確認できた症例だけを収録する。
- 4択式とし、正誤判定後に診断、根拠、鑑別、学び、正式な出典を開示する。
- 日本時間の日付から症例を決め、毎日のCodex実行なしで自動的に切り替える。
- GitHub Pagesはmain更新時に検証を通過した場合だけ自動公開する。
- 大学認証、購読論文、患者資料は使用しない。
